AI 旅游助手 - 需求分析

一、产品解决的真实痛点
在当前的旅游规划场景中，用户面临以下痛点：
1. 做攻略太费时间：用户需要在小红书、马蜂窝等多个平台交叉比对海量信息，耗时耗力。
2. 行程同质化严重：传统攻略往往是“千人一面”，无法根据用户的个人偏好（如预算、天数、喜好）进行个性化定制。
3. 决策成本高：面对陌生的目的地，用户不知道如何安排交通和景点的先后顺序。

我们的解决方案：通过接入大语言模型，用户只需输入简单的自然语言需求（如“帮我规划一份三天两夜的北京穷游攻略”），AI 即可一键生成结构清晰、个性化的行程安排，极大降低了攻略制作成本。

二、项目的核心创新点
1. AI 驱动的个性化交互：抛弃传统的表单式查询，采用对话式交互，深度理解用户的模糊需求。
2. 多模态能力扩展（规划中）：我们不仅生成纯文字攻略，后续计划接入地图 API 与多模态图片生成能力，实现“文字行程 + 实景图片 + 路线地图”的立体化呈现。
3. 轻量级架构与极速响应：基于 Vite + Vue3 构建前端，利用 Vite 代理直连大模型，实现流式输出，带来丝滑的对话体验。

三、系统整体架构
本项目采用前后端分离的轻量级架构，数据流向如下：
1. 用户交互层：用户在网页端（前端 Vue 界面）输入旅游需求。
2. 前端应用层：Vue 3 组件捕获用户输入，通过 fetch 发起网络请求。
3. 代理层：利用 Vite 的 server.proxy 配置进行接口代理，将前端的 /api 请求转发，解决了跨域问题。
4. 模型层：代理层将请求转发至 DeepSeek 大模型 API。大模型接收 Prompt 并返回生成的行程数据。
5. 渲染层：前端接收流式数据，实时渲染 Markdown 格式的旅游攻略展示给用户。

（架构流向：用户 -> 前端 Vue -> Vite 代理 -> DeepSeek 大模型 -> 返回前端展示）
